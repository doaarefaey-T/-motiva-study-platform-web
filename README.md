# MOTIVA public web shell

This repository is intentionally public because GitHub Pages Free serves only public repositories. It contains **only** the browser interface (HTML, CSS, JavaScript and Supabase publishable configuration).

It contains no books, EPUBs, PDFs, MP3s, lesson JSON, server keys, database credentials, private storage objects, or subscription records.

The secure backend, accounts, membership checks and private media are owner-controlled in Supabase. The browser obtains paid content only through the Supabase `motiva-api` Edge Function after server-side authentication and entitlement checks.
